# External dashboard verification

The new `/dashboard` and `/dashboard/orders` routes load the standalone dark dashboard shell. The first automated screenshots were captured during the authentication loading state, so an authenticated browser verification is required next to validate the completed sidebar and live data layout.

The standalone `/dashboard` route opens a polished owner-only login screen with the Qatar Curves Control identity. Authentication is preserved, and the store routes remain unchanged. The authenticated dashboard implementation includes the right sidebar, overview, orders, customers, live visitors, four-second refresh, search, manual refresh, audio toggle, and visual new-order alerts.
